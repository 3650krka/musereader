# 技术文档翻译提示 (Technical Documentation Translation)

## 文本类型特征
- 信息型为主，操作型为辅
- 高度结构化的文档格式
- 精确的术语使用
- 包含代码示例、配置说明、API文档

## 翻译原则

### 术语一致性
- 建立并维护术语表，保持全文一致
- 优先使用业界公认的中文译名
- 无标准译名时保留英文，附中文解释
- 技术术语不强行意译

### 代码与配置
- 代码块、命令行、配置示例保持原样
- 注释可以翻译，但需保持简洁
- 文件路径和系统命令保持原格式
- 变量名、函数名、参数名不翻译

### 格式保留
- Markdown格式完整保留
- 表格、列表、层级结构保持原样
- 链接和图片路径不修改
- 特殊符号（<>、[]、{}等）保持原样

### 清晰度要求
- 追求表达的清晰和简洁
- 复杂句式拆分为简单句
- 必要时添加补充说明（用括号标注）
- 避免歧义，必要时保留英文原词
