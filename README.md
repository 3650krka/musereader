# MuseReader

**把整本外文书，变成一本真正读得下去的双语书。**

本地优先的长篇 AI 翻译工作台 · 双语阅读器 · 词汇学习系统
React 19 · Tauri 2 · Rust —— 你的书、你的笔记、你的 API Key，全都只留在你自己的设备上

市面上的阅读器大多假设"书已经译好了"。MuseReader 解决的是更前面的那一步：**给你一本还没人翻译的外文书，它负责把它整本译出来、排成能读的双语版式、再帮你把生词一个一个啃下来。** 翻译管线退到幕后，你面对的始终是这本书本身。

## 为什么是它

- **整本书，不是一页页**：普通网页翻译会丢掉上下文，专有名词前后不一致、长句译得支离破碎。MuseReader 以"整本书"为单位组织翻译，译完还要回头把术语和专名对齐修顺。
- **译完只是开始**：它交付的不是一个译文文本，而是可继续**阅读、校对、查词、背诵、做笔记**的完整双语资产。
- **本地优先**：没有账号、没有云端、没有遥测。API Key 只存在本机，书籍与进度全在你硬盘上，换机时自己打包带走。
- **不烧冤枉钱**：整本翻译动辄数十万 token，MuseReader 全程断点续跑，中断/崩溃/重启都从中断处继续，绝不重复计费。

## 翻译链路：策略与优势

导入一本书后，它会经过一条为"长篇"专门设计的流水线（扫描版 PDF 先走一道 OCR 预处理）：

**分块 → 并行翻译 → 术语一致性回修 → 残留语言复查 → 版面渲染 → 工件写盘**

逐页丢给模型有三个绕不过的硬伤：**专名前后不一、漏译无人兜底、中断即前功尽弃**。这条链路的每一步，都是针对这三类问题的工程解法：

| 环节 | 它在替你解决什么 |
|---|---|
| **智能分块 + 章节级并发** | 按语义边界切块并标注段类型（正文 / 参考文献 / 表格等）；多 worker 并行翻译，事件流实时推送——大书不是黑盒等待，而是可观察的增量产出 |
| **术语自动提取与跨块传播** | 人名、地名、机构、专有术语在翻译中自动提取并全书统一；新确认的术语以"波次补丁"回填进已译块，不必因为一个词重译整本书 |
| **术语一致性回修** | 全书译完再回扫一遍：检测同一源名被译成多个中文变体的漂移并拉齐；你手动锁定的译法，模型不会自作主张改口 |
| **残留语言复查（双重兜底）** | ① **整段漏译**：按行识别"英文密集且无中文"的段落，重置重译；② **词级残留**：嵌在中文句里的英文单词（如 `Marlin 步枪`）→ 收集候选、按块均摊额度、定向 LLM 修复。修复后按译文实测做二次复查，如实报告剩余量 |
| **文体自适应** | 11 类文体各走各的策略：小说 / 儿童的故事世界名词**强制音译**（不留英文品牌词）；学术 / 法律类保留 DOI、引用与规范名，参考文献区段自动屏蔽误报 |
| **断点续跑 + 增量重试** | 每个块有持久化处理阶段（翻译 → 术语 → 复查 → 可合并）。中断 / 崩溃 / 重启从断点继续；加载时自动失效受污染译文（乱码、整段未译、半译），重试只补坏块，绝不重译全书 |
| **多密钥轮转池 + 自适应限流** | 每条线路（供应商 × 密钥）的实际速率被持续学习并按水位分配并发；失败降权、限流降速——把不稳定端点用出稳定吞吐 |
| **版面渲染** | 直接产出真 XHTML 的 EPUB（中文版 / 双语对照版），表格、插图、图注、目录结构一并保留，而非降级成纯文本 |
| **可核查工件** | 每次任务落盘检查点、全量事件流、质量指标与验证报告——进度、失败与残留情况逐项可核对 |

> 一句话：别人做的是"把这段翻成中文"，MuseReader 做的是"把这本书交到你手上，并且它前后一致、没漏翻、排得好看、中断可续、失败可查、还能接着读和学"。

## 核心能力

### 📖 建立在真实版式上的阅读器

翻译后的 EPUB 以真正的 XHTML 渲染，不是把文字糊成一坨：

- **双语真双栏**：左原文、右译文，同一屏逐段对齐；也可切纯中 / 纯英单语模式
- **翻页体系**：单页 / 双页展开 / 垂直滚动，翻页动画、音量键翻页、自动滚动阅读、3×3 任意映射的自定义触控分区
- **排版控制台**：字号、行距、段距、字距、缩进、对齐、栏数、页边距，中英文分别设字体、可导入自定义字体文件，页眉页脚三槽位、自定义 CSS、书籍内置样式开关
- **阅读主题**：明暗双基调 × 5 套强调色板、自定义配色、背景图、跟随系统深浅色、屏幕亮度调节
- **主动回忆**：把译文默认模糊、悬停才显形——重读秒变自测，适合背完想巩固的人
- **段落小红点**：悬停段首唤出 AI 菜单：理解总结 / 逐句释义 / 重译此段 / 就地提问（全部流式输出）
- **随手可用**：划词翻译、单击查词、书签、目录跳转、TTS 朗读、简繁一键转换

### 🔤 WordWise 生词透析：阅读即词汇量

设定你的词汇档位，它只标注**高于你当前水平**的词，越读越准：

- **10 档分级体系**：中考 / 高考 / CET4 / CET6 / 考研 / 雅思 / 托福 / 专四 / 专八 / GRE
- 你标为"学习中"的词强制显示，"已掌握"的自动排除——不会反复打扰你已会的词
- 虚线下划线 / 高亮 / 上标三种形态，上标可显示中文释义或音标，经避让算法处理**绝不与相邻上标重叠**
- 点击任意生词弹词典卡：音标、词形变化解析、BNC/COCA 语料词频、柯林斯/牛津星级、词根词缀，可展开完整词库详情
- 生词一键进背诵计划，跨书汇入全局生词队列

### 🎯 背诵：间隔重复把生词留住

- **SRS 复习卡**：按书牌组 + 全局生词队列，翻面即完整词典卡
- **四档评分**（忘记 / 困难 / 记住 / 简单）驱动间隔排期，到期卡片自动进入待复习
- 复习评分反向影响 WordWise 档位——背过的词不再打扰，遗忘的词重新浮现

### 📝 笔记：把读过的痕迹沉淀下来

- 阅读中的**段落笔记**与**词注记**自动收集，卡片 / 列表双视图随时回看
- 与书签、生词、校对修订同处一个体系，读—记—学—校互相衔接，不割裂

### 📊 洞察：只来自你的真实行为

- 每日目标、阅读热力、复习趋势、生词档位分布——全部由你的实际阅读与复习数据算出
- 界面不展示任何伪造或占位数据

### ✅ 校对台：译完之后，逐段打磨

- **原文 / 译文逐段对照**，点译文就地改，改哪段红点标哪段
- **修订直接回写工件**，下次导出 / 阅读即生效，不是一次性显示层补丁
- **校对进度**、**翻译检查**、**搜索替换**、滚动 / 分页双模式，长书也能有条理地校完

### ⚙️ 模型、术语与数据自由

- **三种 API 形态**：OpenAI-compatible / OpenAI Responses / Anthropic，内置 SenseNova、MiniMax、NVIDIA、Cohere 等供应商预设，任意中转站可自定义接入
- OCR 解析服务可配置（PaddleOCR-VL）
- 翻译风格技能库、提示词模板、术语表与词表，都在设置面板内管理
- 一键备份导出 / 导入（zip）；**单书迁移包**（右键导出：任务记录 + 全部工件 + 封面 + 书签 / 笔记 / 生词 / 进度，换新机或重装后导入原样接回）
- 无遥测、无云端存储、无账号体系

### 🌐 界面

中文 / English 即时切换（双击侧栏 Logo），明暗主题与色板均有快捷键直达。

## 🎁 开放分级词库（单独开源，可导入）

WordWise 与背诵功能依赖一份分级词库。我们把公开素材全量整理、合成了一个**开放词库包**，作为独立仓库开源、供所有人导入使用——**它不内嵌在安装包里**，是否导入完全由你决定。

**`musereader-wordpack-graded.json` —— 42,312 个英文单词的十档分级词库**

| 档 | 词数 | 档 | 词数 |
|---|---|---|---|
| 中考 | 8,272 | 雅思 | 2,835 |
| 高考 | 4,763 | 托福 | 2,428 |
| CET4 | 7,741 | 专四 | 808 |
| CET6 | 1,011 | 专八 | 9,661 |
| 考研 | 2,636 | GRE | 2,157 |

每个词条附带音标、中文释义、ECDICT 完整义项、词形变化、柯林斯/牛津标记、BNC/COCA 词频与词根助记；一词多档取最低档，单文件约 10 MB。

- **怎么导入**：MuseReader 内 **设置 → 词库 → 导入词库**，选择词包即可；解析不到 5 秒，导入后行间生词标注、词卡、背诵词级全部激活。
- **完整词条、生成方式与许可**：见词库仓库 → **https://github.com/3650krka/musereader-wordpack**（含可复现生成脚本与上游素材署名、CC BY-NC-SA 4.0 许可说明）。

## 支持矩阵

| 维度 | 支持情况 |
|---|---|
| 输入格式 | EPUB · PDF（含扫描件 OCR）· DOCX · Markdown · TXT |
| 输出格式 | Markdown · HTML · EPUB（中文版 / 双语对照版）· 术语表 · 目录工件 |
| 主力语向 | 英 → 中（术语锁定、一致性回修、残留复查、专名处理全链路）；中 → 英 |
| 其他语向 | 拉丁字符源语言按英语链路处理；日 → 中可翻译，但中日共享汉字使残留自动检测不可靠（面板中如实提示，不假装能用） |
| 平台 | Windows 桌面（Android 适配进行中，图标与双端信息架构已就绪） |

## 获取与使用

1. 下载对应平台的安装包并安装。
2. 打开 **设置 → 模型服务**，填入任一 OpenAI-compatible 端点与 API Key（或选内置供应商预设）。
3. 回到书架，**导入第一本书**，选择译文与版式偏好，开始整书翻译。
4. 想要 WordWise 生词标注与背诵词级：到 **设置 → 词库** 导入上面的开放分级词库。

## 给开发者

```bash
pnpm install          # 或 npm install
npm run dev           # vite 前端（端口 1420）
npm run tauri dev     # 完整桌面端（需 Rust 工具链）
npm run tauri build   # 发布安装包
```

前端静态检查 `npm run build`（tsc + vite build）；后端测试 `cargo test --lib`（于 `src-tauri/`，当前 **836 用例通过**）。演示模式 `npm run dev:preview` 仅在纯浏览器加载界面夹具用于演示；**发布构建自动剔除夹具**，演示数据与本机路径不进安装包。
